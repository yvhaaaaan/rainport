# 弯道档案

## 开始游玩

**Windows x64**　安装 Node.js 22 或更新版本后，双击源码目录里的 `start.cmd`。脚本会安装缺少的依赖、启动本地节点并打开游戏。游戏期间请保持启动窗口开启，下次启动会继续读取现有存档。

**从源码启动**　使用 Node.js 20 或更新版本。在项目目录运行以下命令，然后打开 [雨港发车区](http://127.0.0.1:8787/)。

```sh
npm ci
npm start
```

**单文件练习**　双击 `practice.html` 可离线游戏。练习资产写入浏览器本地存储，钱包页标明练习模式。要体验真实区块、签名和回执，请使用上方的本地链入口。

### 使用 Hyperledger Fabric

Fabric 模式使用通道 `rainport` 和同名链码。车手身份来自 MSP 证书，车辆、部件、装配、赛果摘要、订单与 CR 余额由链码维护。整车交割和货款分配由同一个 Fabric 交易提交。赛后回放依旧作为本地文件保存，播放前与链上摘要核对。

本地启动脚本支持 Windows x64 与 Linux x64，可直接启动节点和链码服务。需要 Node.js 22.12+、Go、curl、tar 和可下载 GitHub 与 npm 依赖的网络。从项目目录安装依赖并启动 Fabric 2.5.16 节点。

```sh
npm ci
npm --prefix fabric ci
node fabric/local-network.mjs
```

保留节点窗口。在另一个 PowerShell 窗口执行以下命令，然后打开 [Fabric 版雨港](http://127.0.0.1:8789/)。

```powershell
node fabric/init.mjs
$env:RAINPORT_LEDGER='fabric'
node play.mjs
```

在 Bash 中用 `RAINPORT_LEDGER=fabric node play.mjs` 启动网页。Fabric 的本地网络、证书和密钥保存在 `.fabric-local/`，比赛文件默认保存在 `data-fabric/`。以太坊版仍通过 `npm start` 启动，默认使用端口 8787。两种模式各自保留资产、订单和履历。

已有开发通道时，部署 [链码](fabric/chaincode/) 后，可通过 `FABRIC_CONFIG` 指定 Gateway JSON。配置需要 `endpoint`、`hostAlias`、`tlsCert`、`channel`、`chaincode` 及 `identities`。身份映射包含裁判、A、B、C、港务车队、手续费。每项填写 `mspId`、`certificate`、`privateKey`，文件路径以配置目录为基准。首次初始化使用 Org1MSP 管理员证书。

当前 Fabric 网络是单组织的本地演示。浏览器选择演示身份，由本机服务使用对应证书签名。抽奖使用确定性模拟随机源。Fabric 钱包页显示真实通道、链码、交易 ID、区块号和验证状态。

七项链上验收会跑三场比赛并买卖演示资产，请在另一套新建的开发链上运行。PowerShell 中可用单独的目录与端口启动。

```powershell
$env:RAINPORT_FABRIC_NETWORK="$PWD/.fabric-local/acceptance"
$env:RAINPORT_FABRIC_BASE_PORT='17150'
node fabric/local-network.mjs
```

保留这个节点窗口，在另一窗口指向验收网络，初始化后执行测试。脚本按真实赛时推进，完成后把断言、赛果和节点回执写入 `evidence/fabric-*/`。

```powershell
$env:FABRIC_CONFIG="$PWD/.fabric-local/acceptance/gateway.json"
node fabric/init.mjs
node fabric/acceptance.mjs --fresh-local-network
```

Windows x64 本地 Fabric 2.5.16 实测七项全部通过。三场比赛分别用时 84.823、84.814 和 86.856 秒。整车成交一笔扣 500 CR，卖家实收 490 CR，手续费 10 CR。两个买家同时提交时，一笔通过，另一笔由节点标记为 `MVCC_READ_CONFLICT`，未扣商品款。[七项验收断言](evidence/fabric/checks.json) · [32 份节点回执](evidence/fabric/node-receipts.json) · [试玩版回执截图](evidence/fabric/demo-receipt.png)

### 实际驾驶

比赛进入全屏追车视角。三秒灯号后起步，发动机音调随转速与自动换挡变化。雨天入弯时提前减速，缓打方向，再沿岸全油门。跟车过近会受到前车阻挡，侧面接触、压路肩与碰护栏会反馈到车速和镜头。右上角可切换声音。浏览器支持 WebGL 2 时使用原创 GT27 三维车模；缺少 WebGL 2 时启用兼容画面。

新比赛使用平面自行车模型，驾驶输入和动力学以 10 毫秒为间隔处理。两侧方向键重叠时，后按的方向优先。刹车优先于油门，松开刹车时仍按住油门就会恢复加速。触控可以一手打方向，一手在油门和刹车间滑动。左上角显示下一弯的方向、距离和必要时的建议车速。历史幽灵沿用各自记录的轨迹和当时的物理版本。[操控对照测试](evidence/usability/handling.json)

同一段 12 秒键盘驾驶在 Chrome、Radeon 780M、1280 × 720 下复测。正常本机连接时，画面里车辆向后跳动从 9 次降到 0 次。加入 150–250 毫秒往返延迟后，超过 50 毫秒的车辆位置停顿从 41 次降到 0 次。新版在延迟测试中有一帧耗时 77.3 毫秒。湿地 100 km/h 刹停测试中，公路胎需要 51.98 米，R2 雨胎需要 43.28 米。[逐帧对照](evidence/motion/comparison.json) · [制动与擦碰测试](evidence/driving-v3.json)

### 第一圈

1. 在「比赛」选港务借用车，点「本场奖池」查看四档名次概率和各档可得部件，再点「进入雨港」。方向键或 WASD 控制油门、刹车和转向；手机可同时按住方向键和踏板。
2. 跑完湿弯和沿岸直道后，点「开启奖箱」。赛后奖箱会按本场名次列出掉率。卡带减速停下后会揭晓部件的真正编号，或显示本场未掉落。想马上看成绩，可点「直接查看结果」或「跳过动画」。获得配件后点「装配掉落部件」核对新旧编号，也可以点「装车再跑」追逐本圈幽灵。
3. 在「展馆」点展车上的部件编号查看来源、参赛与成交履历。港务车队的 #010 用 #012 雨胎创造纪录，当前交付清单装的是 #021 公路胎。可挑战原纪录，或签名购买当前展示的四个编号。

使用固定驾驶策略对照，标准车用时 86.744 秒。R2 雨胎让湿弯快 1.849 秒，E3 引擎让直道快 3.992 秒。高下压力尾翼让湿弯快 0.526 秒，直道慢 0.693 秒。各发行版共享同型号驾驶参数。[驾驶测试](evidence/usability/driving-v4.json)

每场有效完赛独立抽取一次。开箱动画读取已经结算的赛事记录，翻到的其他卡片用于展示本场奖池。可从历史结算点「重看开箱」，播放期间刷新会直接回到同一个结果。声音设置与驾驶界面共用，系统开启「减少动态效果」时会直接揭晓。

## 给自己的车换件

打开「车库」，也可以从「比赛」的发车准备区点「打开装配台」。先选自有底盘，再点拆解图或下方的引擎、轮胎、尾翼槽。仓库菜单会列出该槽位适配的部件。点「装入」并签名，一笔交易就能装上新件、把旧件放回仓库。展开「我的独立部件」，可以查看旧件履历或挂牌出售。

从结算页进来时，工作台会定位到本场掉落的编号。已经装好的部件会显示所在底盘。三个槽位齐全后可以用当前配置发车，或追逐刚才那圈的幽灵。借用车配置固定，借车比赛的掉落同样归玩家钱包。整车挂牌后可先打开订单撤单，再继续改装。

## 三种交易

个人卖家从「市场 → 我要出售」选择自己的部件或整车。未装车的部件可直接挂牌。选择「拆下并出售」时，先确认拆件，再选择按编号或同款挂牌。没有自有底盘的车手也可以出售部件。「我的在挂订单」可打开订单详情、撤单和查看回执。[个人出售界面](evidence/fabric/seller-screen.png) · [Fabric 挂牌、买入与撤单回执](evidence/fabric/seller-checks.json)

| 想买什么 | 怎么成交 |
| --- | --- |
| 同型号、规格与版本的部件 | 「市场 → 按型号买部件」。可买最低卖价、托管最高愿付价挂求购，或卖给最高求购。跨价按在簿订单价格成交，同价按挂牌先后撮合。撤单和低价成交退回相应托管款。 |
| 有履历的特定原件 | 「车库 → 拆下 → 编号出售」。买家在「按编号买藏品」打开原件展签，按按钮上的编号购买。指定编号订单独立成交。 |
| 完整赛车 | 「车库 → 整车挂牌」。锁定底盘、引擎、轮胎、尾翼后暂停换装及参赛。买家签名前核对四个编号与代表成绩。一次购买以同一笔交易完成付款、2% 手续费分配及全部过户。 |

在「钱包」右侧切换 A、B、C。可以用两个独立浏览器窗口分别操作买卖双方。订单详情可打开本地节点回执。出售最后一辆自有车后仍可选择借用车。

## 本地链与存档

- 网页端口默认 8787，RPC 为 `http://127.0.0.1:8545`，链 ID 为 31337。端口可用 `PORT`、`RPC_PORT` 修改。网页和节点均绑定本机回环地址。
- `npm run deploy` 可单独编译、部署并初始化空库。服务器启动时也会执行这些步骤。默认存档位于 `data/`。使用新的 `RAINPORT_DATA` 空目录可开启新的世界。一个数据目录同一时间供一个节点使用。
- 双击启动时会优先采用带有实录和初始库存的 `demo-seed/`。若初始挂单即将到期，或从空库部署，服务器会发放新库存，港务车队在后台实跑第一圈，约 80 秒后以 500 CR 挂出展车。
- 首次编译和部署需要一些时间。使用随包 Node 24 时，Ganache 可能提示使用 JavaScript 网络实现，随后会继续启动。

节点使用公开开发助记词 `test test test test test test test test test test test junk`，路径为 `m/44'/60'/0'/0/i`。账户已预充测试 ETH。游戏使用节点解锁的本机演示账户，玩家在游戏内确认单笔签名。四个交易角色初始已授权市场使用最多 1,000,000 CR。

## 实现与复核

- [Archive.sol](Archive.sol) 中的 `Credits` 为 ERC-20，`Archive` 为 ERC-721，并保存装配、赛事、奖励与订单。底盘和部件共享一个编号空间。整车成交保留三组装配关系，直接转移也受资产状态约束。撮合遍历本地订单簿，适合小规模原型。
- 裁判在开赛交易固定四件套、掉率版本、奖池版本和随机源。浏览器按本机单调时钟模拟并逐帧插值，向服务器提交带序号的驾驶输入。服务器以 10 ms 步长推进新比赛，使用 360 ms 输入缓冲接收按键变化，验证完赛后签署 `confirm`，随后 `draw`。已结算结果可重复读取。未掉落时也完成该赛事与钱包组合的结算。开发随机源为 `LocalMockRandom`，外部随机源可实现 `IRandom`。
- 逐场输入和轨迹保存在数据目录的赛事编号 JSON 文件。链上保存成绩、配置、回放的 Keccak-256 摘要，服务端在播放或挑战幽灵前核对三者。
- [打开七项验收报告](evidence/验收报告.html)。报告可离线打开，包含每项断言、原始回执、区块号和界面截图。日常演示链与验收链分别保存。运行 `node inspect-run.mjs`（便携包用 `runtime\node.exe inspect-run.mjs`）可在 8788 端口打开验收结束时的副本，RPC 端口 8546。

```sh
npm test                 # 独立空链，真实计时跑完三场比赛并执行七项验收
node market-check.mjs    # 价格/时间优先、限价差额与过期释放
node contract-check.mjs  # 直接转移限制和未掉落记账
node equip-check.mjs     # 用验收链副本在 Chrome 中装入掉落部件、拆换、刷新并追幽灵
node reward-check.mjs    # 独立测试链实跑掉落与未掉落，核对指针、钱包库存和重看结果
node driver-sync-check.mjs # 延迟与乱序回包下的输入、预测和校正
node handling-check.mjs  # 短点、反打、回正和制动响应
node driving-check.mjs   # 物理对照和万分位概率枚举
npm run test:practice    # 离线练习适配器
```

`npm test` 每次保留独立的 `evidence/chain-*/`，包括部署地址、节点数据目录、全部回执和三个赛事的输入/轨迹。通过后可运行 `node evidence-report.mjs` 生成最新报告。浏览器复核脚本为 `browser-check.mjs`，可用 `CHROME_PATH` 指定 Chrome 路径。网页入口和单文件离线版均已预构建。修改游戏后，运行 `node build-practice.mjs` 通过 esbuild 从 `game.mjs`、车辆模型与赛道源码重建。三维场景和音效均在本机生成。用 `node browser-check.mjs --drive` 可通过浏览器键盘输入重新跑一圈并截图。
